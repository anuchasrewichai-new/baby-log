# แอปบันทึกลูกน้อย — Phase 1

บันทึก **ฉี่ · อึ (เลือกจากภาพเทียบสี) · นม · น้ำหนัก** ของทารกแรกเกิด
แอปจะประเมินตามอายุของลูกว่า ✅ ปกติ / 🟡 เฝ้าระวัง / 🟠 ควรปรึกษาแพทย์ / 🔴 พบแพทย์โดยเร็ว
ใช้ได้แม้ไม่มีเน็ต และซิงก์ขึ้น Google Sheet ของคุณเองเพื่อสำรองข้อมูลและใช้ร่วมกับคู่สมรส

> ⚠️ แอปนี้ช่วยสังเกตตามแนวทางทั่วไป **ไม่ใช่การวินิจฉัยทางการแพทย์** หากกังวลให้ปรึกษาแพทย์เสมอ

## สิ่งที่อยู่ในชุดนี้

| โฟลเดอร์ / ไฟล์ | คืออะไร |
|---|---|
| `index.html`, `js/`, `css/`, `img/`, `fonts/`, `icons/`, `sw.js`, `manifest.webmanifest` | ตัวแอป (GitHub Pages เสิร์ฟจากโฟลเดอร์หลักของ repo นี้) |
| `apps-script/Code.gs` | โค้ดฝั่ง Google Sheet สำหรับซิงก์ข้อมูล |
| `apps-script/appsscript.json` | ค่าตั้งต้นของสคริปต์ (timezone ไทย) |
| `tests/` | ชุดทดสอบเกณฑ์ประเมิน, API และการทดสอบในเบราว์เซอร์ |
| `PLAN.md` | แผนระบบทั้งหมด (phase 1–6) |

ใช้แอปได้ 2 แบบ:
- **แบบ A — เก็บในเครื่องอย่างเดียว:** ทำแค่ขั้นที่ 2 และ 3 ได้เลย (ข้ามขั้นที่ 1)
- **แบบ B — ซิงก์กับ Google Sheet (แนะนำ):** ทำครบ 3 ขั้น ได้สำรองข้อมูล และพ่อแม่บันทึกร่วมกันได้

## ขั้นที่ 1 · ตั้งค่า Google Sheet (ประมาณ 5 นาที)

1. เปิด [sheets.new](https://sheets.new) เพื่อสร้าง Google Sheet ใหม่ แล้วตั้งชื่อ เช่น `บันทึกลูกน้อย`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด แล้ววางเนื้อหาไฟล์ `apps-script/Code.gs` ลงไป → กด 💾 บันทึก
4. ไปที่ ⚙️ **การตั้งค่าโปรเจ็กต์ (Project Settings)** → ตั้ง **เขตเวลา** เป็น `(GMT+07:00) Bangkok`
5. กลับมาที่หน้าโค้ด → เลือกฟังก์ชัน **`setup`** ในแถบด้านบน → กด **▶ เรียกใช้ (Run)**
   - ครั้งแรก Google จะขอสิทธิ์ → เลือกบัญชีของคุณ
   - ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง (Advanced)** → **ไปที่ ... (ไม่ปลอดภัย)** → **อนุญาต**
     (ขึ้นแบบนี้เพราะเป็นสคริปต์ที่คุณสร้างเอง ไม่ได้ผ่านการตรวจของ Google — สคริปต์เข้าถึงได้เฉพาะ Sheet นี้)
6. กลับไปที่ Google Sheet จะเห็นแผ่นงาน **Logs, Settings, Config** — ในแผ่นงาน **Config** ช่อง B2 คือ **รหัสครอบครัว** (32 ตัวอักษร)
7. ใน Apps Script กด **Deploy (การทำให้ใช้งานได้) → New deployment (การทำให้ใช้งานได้รายการใหม่)**
   - กด ⚙️ ข้าง "Select type" → เลือก **Web app**
   - **Execute as:** `Me`
   - **Who has access:** `Anyone` (ทุกคน)
   - กด **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> **ทำไมต้องเลือก "Anyone"?** แอปบนมือถือเข้าสู่ระบบ Google ไม่ได้ จึงใช้ **รหัสครอบครัว** แทน คำขอที่ไม่มีรหัสถูกต้องจะถูกปฏิเสธทั้งหมด ถ้ารหัสหลุด เรียกฟังก์ชัน `resetFamilyKey` เพื่อเปลี่ยนรหัสใหม่ได้ทันที

**ถ้าแก้โค้ด Code.gs ภายหลัง:** Deploy → **Manage deployments** → ✏️ แก้ไข → Version: **New version** → Deploy (URL เดิมใช้ต่อได้)

## ขั้นที่ 2 · นำแอปขึ้นเว็บ (GitHub Pages ฟรี)

PWA ต้องเปิดผ่าน `https://` จึงต้องฝากไว้บนเว็บ วิธีที่ง่ายที่สุด:

1. สมัคร/เข้าสู่ระบบ [github.com](https://github.com)
2. กด **New repository** → ตั้งชื่อ `baby-log` → เลือก **Public** → **Create repository**
3. อัปโหลดไฟล์ทั้งหมดใน repo นี้ (ตัวแอปอยู่ที่โฟลเดอร์หลัก)
4. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
5. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/baby-log/`

> ใน repository มี**แค่โค้ด** ข้อมูลลูกไม่ได้อยู่ในนั้น (ข้อมูลอยู่ในมือถือและ Google Sheet ของคุณ)
> repo นี้: **https://anuchasrewichai-new.github.io/baby-log/**

## ขั้นที่ 3 · ติดตั้งลงมือถือ

1. เปิดลิงก์แอปจากขั้นที่ 2
   - **iPhone:** ต้องใช้ **Safari** → ปุ่ม **แชร์** ⬆️ → **เพิ่มไปยังหน้าจอโฮม**
   - **Android:** Chrome → เมนู ⋮ → **ติดตั้งแอป** (หรือ เพิ่มลงในหน้าจอหลัก)
2. เปิดแอปจากไอคอนบนหน้าจอ → กรอก**ชื่อเล่น วันเกิด น้ำหนักแรกเกิด อายุครรภ์ และวิธีให้นม**
3. (แบบ B) ไปที่ **ตั้งค่า → ซิงก์กับ Google Sheet** → วาง **Web app URL** และ **รหัสครอบครัว** → **เชื่อมต่อและซิงก์**

### ให้คู่สมรสใช้ร่วมกัน
ส่ง 3 อย่างนี้ทางแชตส่วนตัว: **ลิงก์แอป · Web app URL · รหัสครอบครัว**
อีกเครื่องเปิดแอป → แตะ "มีรหัสครอบครัวจากอีกเครื่องแล้ว? เชื่อมต่อก่อน" → ใส่ URL และรหัส → ข้อมูลลูกจะถูกดึงลงมาเอง

## ใช้งานประจำวัน

- **หน้าบันทึก:** ปุ่มใหญ่ ฉี่ / อึ / นม / น้ำหนัก · ด้านบนบอกว่านมมื้อล่าสุดและฉี่ล่าสุดผ่านมานานแค่ไหน
- **อึ:** แตะภาพที่ใกล้ที่สุดในแสงธรรมชาติ แอปบอกผลทันที — **ถ้าก้ำกึ่งกับภาพสีซีด ให้เลือกสีซีดไว้ก่อน แล้วปรึกษาแพทย์**
- **นมเข้าเต้า:** แตะ "ซ้าย"/"ขวา" เพื่อจับเวลา ปิดแอปได้ เวลายังเดินต่อ · แอปบอกว่ามื้อนี้ควรเริ่มข้างไหน
- **นมขวด:** เลือก นมแม่ปั๊ม/นมผสม แล้วใส่ มล. แอปแสดงปริมาณที่ควรได้ต่อมื้อตามอายุและน้ำหนัก
- **ลืมบันทึก:** เปลี่ยนเวลาที่ช่อง 🕒 ด้านบนของแต่ละหน้าได้ · บันทึกผิดกด **เลิกทำ** ได้ หรือไปแก้/ลบในหน้า **ประวัติ**
- **แดชบอร์ด:** กราฟ 7/14 วัน และสรุปรายวัน · **วันนี้ยังไม่ครบ 24 ชม.** แอปจะยังไม่ประเมินจำนวน แต่ประเมินสีทันที
- **ตั้งค่า → สำรองข้อมูล:** ดาวน์โหลดไฟล์ .json เก็บไว้ได้ทุกเมื่อ

### ข้อควรรู้
- **iPhone:** ถ้าเปิดใน Safari โดยไม่ได้ติดตั้งลงหน้าจอโฮม และไม่ได้เปิดนานกว่า 7 วัน Safari อาจลบข้อมูลในเครื่อง → **ติดตั้งลงหน้าจอโฮม และตั้งค่าซิงก์** จะปลอดภัยที่สุด
- สีบนจอเพี้ยนได้ตามแสงและหน้าจอ ภาพเทียบสีในแอปเป็นภาพวาด ไม่ใช่ภาพถ่ายจริง
- การแจ้งเตือนแบบเด้ง เสียง และสั่น จะเพิ่มใน **Phase 3** (ตอนนี้แสดงเวลานับถอยหลังในแอป)

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| "เซิร์ฟเวอร์ไม่ได้ตอบเป็น JSON" | ตอน Deploy ต้องเลือก **Who has access: Anyone** และใช้ URL ที่ลงท้ายด้วย `/exec` |
| "รหัสครอบครัวไม่ถูกต้อง" | คัดลอกรหัสจากแผ่นงาน Config ช่อง B2 ใหม่ ระวังเว้นวรรคเกิน |
| "เชื่อมต่อไม่ได้" | ตรวจอินเทอร์เน็ต · ข้อมูลยังบันทึกในเครื่องได้ จะส่งขึ้นเองเมื่อออนไลน์ |
| แอปไม่อัปเดตหลังแก้โค้ด | เปลี่ยน `VERSION` ใน `sw.js` ทุกครั้งที่อัปโหลดเวอร์ชันใหม่ แอปจะขึ้นแถบ "มีเวอร์ชันใหม่" |
| ข้อมูลในแอปกับ Sheet ไม่ตรงกัน | แตะปุ่มสถานะซิงก์มุมขวาบน หรือ ตั้งค่า → ซิงก์ตอนนี้ |

## สำหรับนักพัฒนา

```bash
npm test                         # ทดสอบเกณฑ์ประเมิน (19 ข้อ) + API ซิงก์ (6 ข้อ)
node tests/dev-server.js 8765    # เปิดแอป + Apps Script จำลอง ที่ http://localhost:8765 (API: /api)
python3 tests/e2e.py             # ทดสอบในเบราว์เซอร์ขนาดมือถือ (ต้องมี Playwright)
```

- เกณฑ์ประเมินทั้งหมดอยู่ใน `js/rules.js` (ไม่มีการเรียกเครือข่าย) — แก้ที่เดียว ทดสอบที่ `tests/rules.test.js`
- ข้อมูลในเครื่องเก็บใน IndexedDB · ซิงก์แบบ "แก้ไขล่าสุดชนะ" ตาม `updatedAt` · การลบใช้ `deleted: true`
- ภาพเทียบสีสร้างด้วย `art/gen_diapers.py`
